# Module 1 — Docker, SQL, and Terraform

Artifacts in this directory cover:

- running a Python Docker image with an overridden entrypoint;
- connecting containers over a Compose network;
- querying November 2025 NYC Green Taxi data in PostgreSQL;
- defining a GCS bucket and BigQuery dataset with Terraform.

The SQL and Terraform files are committed separately so the repository history
shows each verified milestone.
